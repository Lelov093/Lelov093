## 关于我

我目前主要关注 **LLM-based Agent / Agentic AI**，长期希望探索能够持续运行、积累经验、自主决策、自然交互，并不断适应甚至自我演化的智能体。

目前重点关注：

- **Agent Memory 与经验学习**
- **长时程规划与决策**
- **持续学习 / 终身学习**
- **自进化智能体**
- **Multi-Agent 系统与社会智能**
- **工具使用与 Agent-Environment Interaction**

同时，我也关注能够支撑更强智能体能力的相关方向：

**机器学习 · 深度学习 · 强化学习 · 世界模型 · 多模态 · 情感计算 · 大模型后训练 · AIGC**

## 长期愿景

### 类 JARVIS / FRIDAY 的个人超级 AI

我的长期目标之一，是探索类似电影《钢铁侠》中 **JARVIS / FRIDAY** 的个人 AI Agent：能够长期理解用户、形成持续记忆、感知上下文、自主规划和行动、使用工具，并不断从经验中学习和适应。

### 类 SAO 的 AI-Native 虚拟世界

另一个长期目标，是参与构建真正接近 **“类 SAO 世界”** 的 AI-Native 虚拟世界。

其中的数字角色不再只是依赖固定脚本运行的 NPC，而是能够记住经历、形成关系、自主决策、持续学习和成长，并与玩家、其他智能体以及世界共同演化。

同时，我长期关注并期待 **AGI** 的发展。现阶段更希望从 Agent、Memory、Learning、Planning、Interaction 等具体问题出发，逐步探索更加自主、持续和通用的智能。
