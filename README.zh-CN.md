## 关于我

我目前主要关注 **LLM-based Agent / Agentic AI**，希望探索能够长期运行、持续学习、不断适应并自我演化的智能体，以及多个智能体之间更加复杂的交互、协作与社会智能。

目前重点关注：

* **自进化智能体（Self-Evolving Agents）** —— 自主适应、经验积累与长期演化
* **持续学习 / 终身学习（Continual / Lifelong Learning）** —— 面向长期运行的持续学习与能力成长
* **Multi-Agent 系统与社会智能（Multi-Agent Systems & Social Intelligence）** —— 多智能体交互、协作、关系与社会行为

同时，我也对一些相关 AI 方向保持兴趣：

**AIGC · 情感计算 · 多模态 · 世界模型 · 强化学习 · 大模型后训练 · 机器学习 · 深度学习**

## 长期愿景

### 类 JARVIS / FRIDAY 的个人 AI

我的长期目标之一，是探索像电影《钢铁侠》中的 **JARVIS / FRIDAY** 那样的个人 AI。我希望它不仅能够回答问题、使用工具和处理日常事务，还能在长期相处中逐渐理解用户，积累记忆，感知情境，在适当的时候主动提供帮助，并从一次次交互与协作中不断学习和成长。

### 类 SAO 的 AI-Native 虚拟世界

另一个长期梦想，是参与构建像 **《刀剑神域》（Sword Art Online，SAO）** 中那样高度沉浸的虚拟世界。

我所期待的 AI-Native 世界，不只是拥有广阔的场景与丰富的交互，更是一个能够持续运转、不断演化的世界。其中的角色不再只是按照固定脚本行动的 NPC，而是能够记住经历、建立关系、做出自己的选择，在与玩家、其他角色和世界的交互中不断学习、成长，共同书写属于这个世界的故事。

我也持续关注并期待 **AGI** 的发展。现阶段，从 Agent 的记忆、学习、规划、决策与交互等具体问题出发，探索智能体如何在长期运行中积累经验、不断成长，并逐步走向更加自主、通用的智能。
